We studied before in lecture of networking theory, the 
network‐based systems consist of a server , client , and a 
medium for communication
A computer running a program that makes a request for 
services is called client machine.
A computer running a program that responses to the 
requested services from one or more clients is called server 
machine. 
The medium for communication can be wired or wireless 
network.

UDP socket Programming
 To send and receive a message to a specified hostname on     
port using UDP.
1. Import the necessary classes: DatagramPacket, DatagramSocket, 
and InetAddress from the java.net package.
2. Define the message, length, address, and port: Convert the 
message to bytes, get the InetAddress of the server, and specify the 
port number.
3. Create a DatagramPacket: This packet will contain the message, its 
length, the server address, and the port number.
4. Create a DatagramSocket: This socket will be used to send the 
packet.
5. Send the packet: Use the send method of the DatagramSocket to 
send the packet.
6. Close the socket: Always close the socket after use to free up 
resources.
