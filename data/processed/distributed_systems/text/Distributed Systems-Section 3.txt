Introduction to Concurrency 
What is a task? 
A task is one piece of work that we want the computer to do. 
 Download a file. 
 Play a song. 
 Send an email. 
Example: Your computer is running NetBeans, your browser is downloading a 
file, and Task Manager is open. Each of these is a task. 
What is sequential execution? 
Sequential execution means the computer does the tasks one after another. The 
next task starts only when the one before it is finished. 
Example: A server receives two requests. Request A takes 4 seconds and Request 
B takes 3 seconds. The server finishes A, then starts B. 
 Total time = 4 + 3 = 7 seconds. 
 The user who sent B waits 4 seconds before the server even starts on their 
request. 
What is concurrent execution? 
Concurrent execution means that several tasks are in progress during the same 
period of time. The computer does not wait for one task to finish. It moves between 
the tasks. 
Example: The same server now handles A and B concurrently. While A is waiting 
for the database, the server works on B. Neither user waits for the other to finish.

Processes and Threads 
What is a process? 
A process is a program that is running. When you double-click an app (Chrome, 
Word, a Java program), the operating system creates a process for it. 
 Every process gets its own memory (its own private space). 
 You can see your processes in the Task Manager. 
 
What is a thread? 
A thread is a small worker inside a process. It is the smallest unit of work that the 
CPU can run. 
 A process has at least one thread. It can have many. 
 All threads of the same process share the same memory. 
Think of a restaurant 
The process = the whole kitchen. The threads = the cooks. All cooks work in 
the same kitchen and use the same fridge (shared memory).

Main thread and worker threads 
 When a Java program starts, Java creates one thread for us automatically. It is 
called the main thread. 
 The main thread runs the main() method. 
 The main thread can create more threads. These extra threads are called 
worker threads. Each worker does a job for us.

Concurrent Execution in a Distributed System This program demonstrates the Concurrent 
Execution characteristic of a distributed system. Two independent nodes, Node-A and Node-B, 
perform their tasks simultaneously using separate threads. The main program waits for both 
threads to complete before displaying a final message. 
Code  
package concurrentexecutiondemo; 
public class ConcurrentExecutionDemo { 
    public static void main(String[] args) { 
      // Node-A task  
      Thread nodeA = new Thread(() -> {  
        for (int i = 1; i <= 3; i++) {  
        System.out.println("Node-A processing task " + i);  
      }  
      });  
      // Node-B task  
      Thread nodeB = new Thread(() -> {  
       for (int i = 1; i <= 3; i++) {  
            System.out.println("Node-B processing task " + i);  
        }  
       });  
      // Start both nodes concurrently  
        nodeA.start();  
        nodeB.start();  
      // Wait for both nodes to finish  
      try {  
        nodeA.join();  
        nodeB.join();  
      }   
      catch (InterruptedException e) {  
         e.printStackTrace();  
      }  
      // Final message  
      System.out.println("All nodes have completed their work.");  
    } 
}

package multithreadserver; 
import java.io.*;  
import java.net.*;  
public class MultiThreadServer { 
    public static void main(String[] args) { 
        try {  
            ServerSocket serverSocket = new ServerSocket(5000);  
            System.out.println("Server started...");  
            while (true) {  
                Socket clientSocket = serverSocket.accept();  
                System.out.println("New client connected");  
                ClientHandler handler = new ClientHandler(clientSocket);  
                new Thread(handler).start();  
            }  
        } catch (IOException e) {  
            e.printStackTrace();  
        }  
    }  
}
