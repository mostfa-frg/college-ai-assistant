What is a Distributed System?
Definition (Coulouris et al., p.2)
10 / 26
A distributed system is a collection of independent computers that appears to users as a single 
coherent system. (Coulouris)
Distributed computing studies how to design systems in which independent computers, 
connected by a network, coordinate their actions and share resources by passing messages —
so that together they behave like a single system.
Main Characteristics:
•  Concurrency: Components execute independently at the same 
time.
•  No Global Clock: Components cannot rely on perfect time 
synchronization.
•  Independent Failures: Components can fail independently 
without bringing down the whole system.
•  Message Passing: The ONLY way components interact through 
network messages.
The meaning of:
Independent Computers
Each computer:  Has its own 
memory, Has its own processor,
Can fail independently
Single System View
Users see only one service.

Key Aspects of This Definition
Definition
4/33
1. Autonomous Components: Independent computers operating on their own. Each has its own processor, 
memory, and OS.
2. Single System View: Although many computers are working together, users think they are using one 
system.
3. Collaboration Required: The computers cannot work alone. They must cooperate and exchange 
information.
4. No Assumptions About Computer Types or Interconnections: Distributed systems can contain different 
types of computers and networks (Windows, Linux, Wi‐Fi, Fiber).
Key Idea: Computers are separate and independent, but they must coordinate and communicate to 
appear as one.

Main Points of Middleware
Organization
7/33
1. Logically Placed Between Apps and OS: Applications do not directly interact with hardware or operating 
systems.
2. Distributed Apps: One application can run on multiple computers (e.g., logic on one, database on 
another).
3. Same Interface Everywhere: Applications use services by the same way regardless of where resources 
are located.
4. Hides Heterogeneity: Applications do not need to know which processor, OS, or computer stores the 
data.
Benefits: Hides differences, provides a common interface, supports distribution, and simplifies 
development.

3
Definition: The logical channel through which nodes exchange messages, using protocols like TCP or UDP.

--- Page 26 ---
Components: Resource Sharing
Component 4 of 4
23/3
3
Definition: The ability of multiple processes to access and use a common resource in a controlled and 
consistent way.
Resource Sharing Mechanisms:
1. Client‐Server Model: Clients request, servers respond (e.g., Web browsing).
2. Object‐Based Model: Resources encapsulated as objects, accessed via methods (e.g., CORBA, Java

3. Peer‐to‐Peer (P2P) Model: All participants both provide and consume resources (e.g., BitTorrent).
