Java variable 
 Variables must not start with a number. They can only start with an alphabet, 
underscore (_), or dollar symbol ($). 
 A variable name cannot contain symbols like +, -, ., @, #, *, etc. 
 Keywords (like int, class, void, etc.) cannot be used as variable names. 
 Java is case-sensitive, meaning int abc and int ABC are two different variables. 
Examples: 
 int abc = 10;        // Valid 
 int abc2 = 20;      // Valid  
 int _abc = 30;      // Valid 
 int $abc = 40;      // Valid 
 int @abc = 50;    // Invalid due to the '@' symbol 
 int abc? = 50;     // Invalid due to the '?' symbol 
 int 72abc = 50;   // Invalid  
So, Only letters (a-z, A-Z), digits (0-9), the underscore (_), and the dollar sign ($) 
are allowed in variable names, variable names cannot start with a number.

Java Output 
In Java, println(), print(), and printf() are methods used to print output to the 
console, but they behave slightly differently.  
1. println() (Print Line) 
 What it does: Prints the output and moves the cursor to the next line. It 
automatically adds a new line after the printed content. 
 Use case: When you want the output to be on separate lines. 
 Example 
System.out.println("Hello");  // Prints "Hello" and moves to the next line 
System.out.println("World");  // Prints "World" on a new line 
Output: Hello 
      World 
2. print() (Print) 
 What it does: Prints the output but does not move the cursor to the next line. 
It keeps printing on the same line. 
 Use case: When you want multiple outputs to be printed on the same line. 
 Example 
System.out.print("Hello");  // Prints "Hello" without a newline 
System.out.print("World");  // Prints "World" on the same line 
Output: HelloWorld

Java switch Statement 
The switch statement is used to execute one block of code from multiple options 
based on the value of an expression. It is a cleaner alternative to writing multiple if-
else-if statements, especially when dealing with multiple possible values for a 
variable. 
 
 Expression: The expression inside the switch statement must evaluate to a 
primitive data type (int, char, short, byte), String, or enum. 
 Case Labels: The value of each case must match the type of the switch 
expression. Once a case matches, the corresponding code is executed until a 
break statement is encountered. 
 break: Used to exit the switch statement after executing the matched case.      
Without it, execution will "fall through" to the next case. 
 default: This is an optional case that is executed if no other case matches the 
expression.

Threads 
Node A is a server and receives requests from many clients: 
          Node A (Server) 
          /      |      \ 
         /       |       \ 
     Client A  Client B  Client C 
If Node A uses one thread: 
Client A → finish 
              ↓ 
          Client B → finish 
                         ↓ 
                     Client C 
Each client must wait. 
Using Threads 
Node A can create a separate thread for each client: 
             Node A 
            Server 
               | 
      ┌────────┼────────┐ 
      ↓        ↓        ↓ 
   Thread 1 Thread 2 Thread 3 
      ↓        ↓        ↓ 
 Client A  Client B  Client C 
Now the server can handle multiple clients concurrently. 
 
Concurrency 
Concurrency means multiple clients/tasks are being handled during the same period 
of time. 
For example: 
Thread 1 → Client A 
Thread 2 → Client B 
Thread 3 → Client C 
This is very common in distributed systems because a server may receive many 
requests at the same time.

Program:  
Concurrent Execution in a Distributed System This program demonstrates the Concurrent 
Execution characteristic of a distributed system. Two independent nodes, Node-A and Node-B, 
perform their tasks simultaneously using separate threads. The main program waits for both 
threads to complete before displaying a final message. 
Code  
package concurrentexecutiondemo; 
public class ConcurrentExecutionDemo { 
    public static void main(String[] args) { 
      // Node-A task  
      Thread nodeA = new Thread(() -> {  
        for (int i = 1; i <= 3; i++) {  
        System.out.println("Node-A processing task " + i);  
      }  
      });  
      // Node-B task  
      Thread nodeB = new Thread(() -> {  
       for (int i = 1; i <= 3; i++) {  
            System.out.println("Node-B processing task " + i);  
        }  
       });  
      // Start both nodes concurrently  
        nodeA.start();  
        nodeB.start();  
      // Wait for both nodes to finish  
      try {  
        nodeA.join();  
        nodeB.join();  
      }   
      catch (InterruptedException e) {  
         e.printStackTrace();  
      }  
      // Final message  
      System.out.println("All nodes have completed their work.");  
    } 
}
